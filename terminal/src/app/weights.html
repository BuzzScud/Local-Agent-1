How the file stores a weight

  1. Every big matrix is cut into blocks of 128 weights along each row.
  2. Each weight is kept as one digit, −1, 0 or +1, and each block has one scale. Weight = digit × scale.
  3. Before storing, each row was mixed with a fixed recipe (a Hadamard mix plus sign flips). That spreads out the few big weights so two bits lose less, and it is why the stored digits look like static.
  4. “Real weights” undoes that mix, row by row. The result is close to the original weights, with some fuzz left by the two-bit storage.

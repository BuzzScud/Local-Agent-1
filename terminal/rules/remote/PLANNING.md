# Planning

Read this for a task with three or more steps, several files, or a request with several parts.

## Plan

1. Look first: find the files, callers and tests the task touches before you settle the plan. Named files are a starting point, not the whole scope.
2. Write the plan with TodoWrite: one line a step, in order, each with how you will know it is done (a test passes, the page shows X).
3. Split the request into its parts and give each part its own step, so none is dropped.
4. Work the list top to bottom. Mark a step done only when its result is seen.
5. When something you find changes the scope, change the list and say why in one line.
6. A step you cannot finish stays open, with the reason, in the final answer.
7. Before you finish, read the request again and check each part against what you did.

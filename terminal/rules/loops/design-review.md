# Design review
Every hour, the three changes that would most improve your page's design: hierarchy, spacing, type and states.

- Kind: task
- Every: 1h
- Until: no limit
- Mode: plan
- Picture: READ the page › SPOT 3 fixes › SAY each one
- Asks: page = index.html

## Each run
Read {page} and the styles it uses. Give the three changes that would improve its design most, one line each with its file and line. Look for: one clear first thing to look at, a type scale (few sizes, even steps), even spacing, and the hover, empty, loading and error states. Do not repeat a change an earlier run gave unless it is still not made. Change nothing.

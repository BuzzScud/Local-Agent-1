# Watch the tests
Runs the tests every 10 minutes and says what fails, and what started failing since the last run.

- Kind: test
- Every: 10m
- Until: no limit
- Mode: ask
- Picture: RUN the tests › READ what fails › FIND the cause › TELL you

## Each run
Run the tests. Say which fail and why, and which started failing since the last run. Change no file.

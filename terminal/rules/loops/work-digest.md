# Work digest
Every 30 minutes, five lines on what changed, what looks unfinished and what to commit next.

- Kind: task
- Every: 30m
- Until: no limit
- Mode: plan
- Picture: READ git diff › SPOT loose ends › GROUP the work › SAY next commit

## Each run
Look at git status and git diff. In five short lines: what changed since the last run, what looks unfinished (a TODO, a FIXME, a failing check), and what to commit next. Change nothing.

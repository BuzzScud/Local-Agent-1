# Layout watch
Checks your page every 15 minutes in a hidden browser (desktop, phone, dark mode) and says only what broke or got fixed since the last run.

- Kind: web
- Every: 15m
- Until: no limit
- Mode: ask
- Page check: {page}
- Picture: CHECK the page › COMPARE to last run › SORT new or gone › TELL what changed
- Asks: page = index.html

## Each run
The page check of {page} is above. Say which of its problems are new since the last run and which went away, each with its element and where it shows (desktop, phone or dark mode). If nothing changed, say "no change". Change nothing.

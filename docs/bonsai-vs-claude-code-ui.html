How Claude Code's terminal is made

TypeScript on BunOne bundled program; runs on Node or Bun, ships as a native build too.
React + InkThe screen is React components; Ink renders them to the terminal instead of a browser.
Yoga flexbox layoutBoxes, padding, wrapping and widths are laid out like a web page, then drawn as text.
Repaint on changeOnly the bottom "live" area is redrawn; finished messages are printed once and stay in the scrollback.

Bonsai is built the same way — JSX, React and Ink, compiled by Bun into one file — which is why the two look alike. Where they differ is choices, not technology: what sits on screen all the time (Claude Code: almost nothing), how many commands there are, and Bonsai's extra Live-thinking layout.

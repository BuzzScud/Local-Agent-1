# The files at the top of the project

Its main files with a line each, the rest by name.

- AGENTS-DETAILS.md (400) — Background notes explaining how the agent and model parts work together.
- AGENTS.md (67) — Short rules for working in this repository, kept concise for small models.
- CLAUDE.md (3) — Instruction file linking to the main rule sets for AI agents.
- install.sh (167) — Shell script automating the setup of Agentic Coder on a Mac.
- README.md (554) — Main documentation describing features, installation steps, and usage instructions.

Bonsai terminal: 2 designs

25 September 2026 · Both are the real app, captured in a terminal with a scripted model (so the RAM number is missing). Both now start at the top like Claude, show the status line in either layout, and leave the memory warning to /stats.

A · The Claude look
  • A welcome box as wide as its words: model, folder, /help
  • "Tips for getting started", three lines
  • Status line under the footer: idle · ctx · RAM · effort
B · The slim header bar
  • One header line and a rule instead of the box
  • The tips on one line
  • The status folded into the footer's right side, one line fewer; narrow windows drop the least important parts first

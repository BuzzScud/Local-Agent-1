It is Alibaba's Qwen3.8-27B, retrained by Prism ML so that every weight is one of three values with one shared scale per 128 weights. Prism says it keeps 98.2% of the original's benchmark score at about a ninth of the size.

The 64 layers

A word passes through all 64 layers, top to bottom, in 16 groups of four. Three layers in each group carry a running memory that stays the same size however long the conversation gets. The fourth looks back over every earlier word, and only those 16 layers need the growing word cache. That is why a 32k-word conversation costs this model so little memory.

running-memory layer (48). Gated DeltaNet: memory 128 × 128 per head, 48 headslook-back layer (16). 24 question heads share 4 key/value heads, 256 wide

Where the 7.2 GB goes

Every word written pulls nearly all of this through the chip once. The thinking part of each layer (the feed-forward block) is almost two thirds of it.

Counted over 205 million decoded weights from 8 places in the model (first and last layers, the vocabulary tables). All three values are used almost equally, everywhere.

The scramble before every multiplyBefore each multiply the engine shuffles the incoming numbers with a fixed ±1 pattern, 1,024 at a time (a Walsh–Hadamard transform). Big spikes get spread out evenly, so three levels are enough to hold them. The weights were trained in that shuffled form. Prism names this step as the biggest cost left per written word, apart from the multiplies themselves.
What stays at full precision (0.1%)26.2 million numbers are too small to be worth squeezing and too sensitive to risk: the gates and 4-tap filter of the running memory, and the layer norms. Together they are 58 MB of this file.

The way past the ceiling: guess ahead, check in one go

A small helper model guesses the next several words; Bonsai checks all the guesses in one pass and keeps the ones it agrees with. The output is the same, only faster, if checking several words costs about the same as writing one. On this Mac today it doesn't:

Total time121 ms255 ms421 ms865 ms563 ms585 ms
Per word121 ms127 ms105 ms108 ms35 ms18 ms
The helper exists, as of todayDFlash2 is a 1.1 GB helper that guesses 7 words at a time. A version re-fitted to Bonsai 2 exists, and Prism merged support for it into their engine's source on 25 Sep, after the release we run. On an Nvidia L4 it took code from ~30 to 65.6 words/s. Prose barely changed (28.9).
The missing piece for MacsAlso today, Prism added a "check 2 to 4 at once" routine for the other file format (PTQ1_0), switched off by default. On an M5 Max it turned guessing from a loss (13.0 words/s against 30.2 without) into a win (39.5). Nobody has written that routine for PQ2_0 yet.

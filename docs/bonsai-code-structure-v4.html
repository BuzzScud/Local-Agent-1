Bonsai Code: how the folder is structured version 4

One repo, two parts. terminal/ is the agent you talk to; models/ holds the models it runs and the bench that tests them. They meet at one file, models/index.mjs. The model's weights and your conversations live on this Mac, outside the repo.

New in version 4 (25 Sep 2026): the test bench is grouped.
  • run.mjs, tasks/, words/ and night/ moved into models/evals/bench/, the tests themselves. evals/ now has four entries: bench, reports, tools and dev.
  • Commands are unchanged: bun run eval and bun run eval:words point at the new paths. Speed is unchanged.
  • Earlier versions sit beside this file: v1 (commit 047a8be), v2 (6c52902) and v3 (906e0c4, the compact tree).
terminal/ · part 193 files · 5,300 lines of code in src/ · the screen, the loop, the focused paths, the tools
models/ · part 2302 files · 2,900 lines of code + 28 practice projects · one folder per model, the runtime, the test bench
On this Mac, not in git~/.bonsai-code: the 7.2 GB model, 418 MB of saved warm-ups, llama-server, your sessions · the installed bonsai

Type /permissions, or pick Permissions at the top of /settings. Each row shows what it holds now, and enter opens it. /mode and shift+tab still change only this conversation.

Each row prints its list, numbered, with where each rule applies (this folder, or every folder). The fixed rules are listed too; no saved rule can lift them.

When it asks about a command there is a new choice, 3. It saves a rule for this folder, runs the command, and the command never asks again here, in this window or the next.

Today "don't ask again" remembers a command's first two words, so anything chained after them runs too. Now every part of a chain has to be covered, and the question offers to remember only the part nothing covers.

What a rule covers

  • npm test covers npm test --watch and npm test -- foo, not npm test other or npm run test
  • rm notes.txt never covers rm notes.txt other.txt
  • A rule ending in * covers anything after it: git add *
  • In a && b, a; b, a | b or two lines, every part needs a rule, or only reads

A command written over two lines is two commands. Today, a first line that only reads (ls) made the whole command count as reading, so the second line ran without a question.

In Auto-edit, file changes go through without asking. Now some files always ask, even in Auto-edit: secrets, keys, git's own folder, this app's settings, and any you add with /permissions protect.

Built in

.env .env.* *.pem *.key id_rsa* id_ed25519* .git/ .agentic/settings.json .agentic-coder/

A link to one counts as the file itself (notes.md → .env), .ENV counts as .env, and reading them is unchanged. .agentic/settings.json could turn Auto-edit on; .agentic-coder/ holds your saved rules when you work from the home folder.

Your never-list holds in every mode, Auto-edit and coding -p --yes included. Every list can also be changed by typing; a rule that can't be one is refused with the reason.

/permissions test <command> says what that command would do here, and why, part by part. Nothing is run. /permissions test edit <file> tries a file change.

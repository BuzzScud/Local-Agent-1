Things you should know

  • The service doesn't report its total memory. So /subagents can't show "room left ~38 GB" as in your sketch. It shows what's loaded now and each helper's size instead.
  • The second opinion. gpt-oss is 65 GB and your main model is 52 GB, which likely don't fit together, so each check would unload your model. Picked after this preview: Qwen3.6 (24 GB), which fits beside it. gpt-oss stays one ← → away in /subagents.
  • The / menu is full. It holds 18 commands, which is all that fits an 80×24 window. My plan: when you're on a service, /subagents takes the place of /start and /stop (they only load the model on this Mac).

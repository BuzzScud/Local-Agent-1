Today

  1. Enter on a model switches at once.
  2. The only knob is a small Effort row at the bottom: Low or High (only Low on a model that cannot think).
  3. The real limits live in /effort, one set for every model.
  4. On a service the Thinking cap is not a thinking limit (Ollama has none). It only lengthens each reply: Laguna at High got 6,144 tokens for thinking and answer together.

New

  1. Enter opens that model’s own settings. Nothing loads yet.
  2. Thinking shows the model’s real choices: Laguna Off · Max, Qwen3.6 and Ornith Off · On, gpt-oss Low · Medium · High, the coders None.
  3. Each row shows what your ranks page suggests; s fills them all in.
  4. enter switches with them; esc goes back to the list, still on the old model.
  5. Each model keeps its own. Laguna keeps its 10 min and 128k; the next model has its own, or the shared ones.
  6. On the model in use (✔), the same menu saves at once.
  7. The model’s own limits on the service: Reply length, Temperature, Presence penalty, Keep loaded.

The four rows

  • Reply length: how long one reply may run, thinking and answer together. Ollama’s only stop: a model that thinks past it answers nothing. Auto = today’s (2,048, plus the Thinking cap while it thinks). Never more than the context has left.
  • Temperature: its own, or 0 – 1. Lower = steadier, the same kind of answer each time.
  • Presence penalty: its own, or 0.5 – 2. Raise it when a model repeats itself or loops (your ranks page says so for Qwen3.6).
  • Keep loaded: while this window is open (today), 30 min or 5 min idle. Shorter frees the service’s memory; the next reply then waits while it loads.

Suggested Reply length from the ranks page: Laguna S/XS 32k, Qwen3.6 32k, Ornith 8k. No numbers for Temperature or Presence penalty there, so none are suggested.

Where it is kept

  • In the service’s saved set-up, next to each model’s Context (which was already kept per model).
  • Only the rows you move are kept. A row you never touch follows the shared value, so a new default still reaches it.
  • Shared by every model: Who decides. This Mac’s own models keep today’s one-set /effort.
  • Search on a service is the service’s own (/subagents gives one of its models the code search), so /effort there has no Search rows. This Mac’s search stays as saved, in /effort on This Mac.
  • coding -p uses the model’s own settings too.
  • The last row, Use shared, puts a model back on the shared settings.

Edge cases

  • A model without tools: asked first (as today), then its menu.
  • In the middle of a reply: enter says to wait; nothing is saved or switched.
  • A model that does not load: back on the old one, and the old one’s thinking is left alone.

1 · Cards your option 1: plain sentences

      
Each loop is a card with four lines in words: Now what it is doing, Last how its last run ended, Next when it runs again, You your last note and whether it was read. Under the cards, all that happened, newest first.

      
+ Nothing to decode: the bars and the LOOK / WORK / REPORT / WAIT steps are gone.

      
− Three cards fit across; a long answer is cut to two lines (^G opens the whole run).

    

    

      
2 · Live your option 3: the conversation

      
The picked loop's run as it happens, drawn like the chat: each step and its result, your note where the run read it, then its answer. Earlier runs fold to one line each. The loops are tabs along the top; ↑↓ moves between them.

      
+ You see exactly what it does; nothing is guessed from tool names.

      
− One loop at a time: the others are a word in their tab.

    

    

      
3 · Track new

      
A loop is about time, so each loop is a lane on a clock: a mark for each run (green passed, red failed), the run under way growing up to the now line, and ○ where the next runs will be. Under the lanes, the picked loop in sentences.

      
+ When each loop ran, how it went and when it runs next, for all of them at one look.

      
− New to learn; at 45 s a cell, a run is one cell wide.

    

    

      
4 · Messages new

      
Each loop is a conversation, as in a messages app. Its runs report to you as messages; your notes go on the right and say read after step 1; a question comes with numbered answers. The list on the left shows which loop has news.

      
+ Telling a loop what to do is just writing to it: nothing to learn.

      
− It shows results, not every step (^G opens the whole run).

    

    

      
In all four

      
    
        
  • The same window. /loops switches this window's screen; esc goes back to the chat, where one line above the prompt shows the loops.
    • 
        
  • Typing goes straight in the box. No key to press first, and no letter is a command.
    • 
        
  • Commands are ctrl keys: ^N new · ^R run now · ^P pause · ^S stop · ^O rules · ^X start over · ^B undo · ^G whole run · ↑↓ pick a loop.
    • 
        
  • Stop asks, and only y stops it. Enter does nothing there; s then Enter is probably how test5m was stopped.
    • 
        
  • A note stays in sight: "sent", then "read after step 1", or "waits for its next run".
    • 
        
  • A loop that ended: type a note and Enter starts it again with it.
    •

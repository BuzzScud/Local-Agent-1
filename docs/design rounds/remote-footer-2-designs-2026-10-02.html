Gauges on the left

The left side, which only says "? for shortcuts" after your first message, becomes an instrument strip: speed with the last eight replies, context and GPU as bars. The right keeps the model, where it runs and the mode.

coding
  • More fits at 80 columns, because both halves of the row carry numbers instead of the right half alone.
  • "? for shortcuts" shows while there is nothing to measure (connecting, not answering). A note such as "copied" takes the gauges' place for a moment, as it takes the hint's place today.
  • The bars turn amber at 70% context and red at 85%, the same points as today's memory warning. In a spill, the GPU bar's amber part is the share running on the CPU. The cost moves to /meters.

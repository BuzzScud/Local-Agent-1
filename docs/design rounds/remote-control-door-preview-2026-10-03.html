Remote control · the door between your Macs, made solid

Preview · 3 Oct 2026 · the real app, with this Mac playing server-1 · nothing pushed · keys 1–7, ← →

Today (on main)

  1. coding attach server-1 lists what runs there and has one more row: start a new session. It always starts in server-1’s home folder, which then offers two places: home, or Agentic Coder’s folder.
  2. A session you start from here runs on server-1 with no window there. Server-1’s screen shows nothing.
  3. Nothing on the screen says which Mac you are typing into.
  4. If the link drops, your window freezes with no message. It never comes back by itself.
  5. On server-1, a window whose Mac went to sleep is counted as open for ever, the session stays drawn at its size, and the door keeps everything drawn for it in memory, with no limit.
  6. The wrong-key limit (5 a minute) can be skipped by opening many connections first.
  7. The session keeper keeps no log.

New (this build)

  1. The menu offers the folders you worked in on server-1, its home, a folder you type, or its last conversation carried on.
  2. A session you start from here opens a window on server-1 by itself, at your window’s size. Both screens show the same session; either can type.
  3. The footer says ⇄ on server-1 while another Mac has a window on the session.
  4. A lost link says “Connection to server-1 lost, reconnecting…” and comes back by itself. ctrl+b stops the waiting.
  5. A window that has said nothing for 35 seconds, or is 16 MB behind, is let go: no longer counted, no longer what the session is sized to, nothing more held for it.
  6. Five wrong keys from one address refuse it for a minute, however they are sent.
  7. Each session’s start, windows and end go into one log file. An older app on either Mac still works, and is told to update.

What is real here

  • Every screen is the real app (this build), driven by keys in a pretend terminal and read back cell by cell. Nothing is drawn by hand.
  • “server-1” is this Mac: a real door on 127.0.0.1 named server-1, in a throwaway home. The two folders were made for the page and removed.
  • The model is a stand-in and off; no message was sent. The screens show the session, not an answer.
  • Server-1’s window in tab 3 is a second pretend terminal, started the moment the door asked for a window.

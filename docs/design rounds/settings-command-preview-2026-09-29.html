vs. the sketch you picked

The sketch put Pages and Tools on one line each. In the build every item gets its own row, so ↑↓ works the same all the way down, the way /mode and /meters already work.

Every row runs the same command you'd type, so its output looks exactly the same as it does today. On enter: Status bar opens the On / Off menu (as /meters). Helpers, Rules, Memory, Stats and Doctor print their panels. Instructions and the four Pages open the hub in the browser. Init writes AGENTS.md, and Update restarts on new code.

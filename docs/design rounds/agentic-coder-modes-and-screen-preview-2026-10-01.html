2 · The model can look at your screen (never click)

  1. A new Screen tool: a picture of one app's window, or the whole screen.
  2. Offered only to a model that can see pictures: Qwen3.5 9B and Gemma here, Qwen3.6 35B and llama4 on your Ollama box.
  3. Once per app (your pick): This time · For this session · Always · No. Bypass doesn't ask.
  4. macOS must allow it first. Your Terminal does not have Screen Recording yet, so /screen setup opens the right System Settings page. It's one switch, then reopen Terminal.

What's real on this page

  • Every terminal screen is the real app, today's code vs the new code, driven in a terminal emulator. Only the model's replies there are scripted (a stand-in), so the screens are the same every time.
  • The screen picture there is a stand-in too (a drawn “TextEdit” window), because Terminal can't take real ones yet.
  • The two “Real model” tabs are the real model (Qwen3.5 9B on this Mac) judging 16 steps and looking at a window: a new Arena check you can run again yourself.

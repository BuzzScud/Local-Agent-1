What is real here
  • Measured at 1:39 PM with the app's own helpers (availableBytes, needBytes, the server's footprint + model file), plus sysctl for swap and memory pressure.
  • Worked out: the "Fresh start" moment adds Gemma's 7.0 GB back to free and assumes green pressure. Run coding stop and I can measure it for real.
  • How it updates: the welcome box is printed once, when the app opens, like Claude Code's. So as built today it would show the numbers at that moment, and they'd scroll away with it. A live version is a separate choice.
  • At 80 columns there is no room beside the box, so every design hides and the welcome box looks as it does today.

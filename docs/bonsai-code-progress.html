Done in round 2

  1. Sorting requests into question / rename / fix / change / other, by simple rules, or by the model with its reply forced into a fixed JSON shape when the rules can't tell. Questions and anything else still use the round 1 step-by-step loop.
  2. Built-in rename: every whole-word use in every file, one diff, one question. No model, and instant.
  3. Fix path: run the tests → find the file (from the failure, from names in your request, or the model picks from the file list) → up to 8 tries in a scratch copy of the project → the first try that passes is shown as a diff for your OK. Each new try sees its previous wrong version and the exact failure (e.g. 3 !== 2.5). In two runs, both fixed the bug on the 2nd try.
  4. Feature path, test first: 3 candidate tests (each must fail today for the right reason) and 4 drafts written from the task alone, then a cross-check that keeps the test the drafts agree with, so tests that invent extra requirements are caught. Then your approval of the test, then the change (a draft that already passes is used straight away; otherwise up to 8 tries with feedback).
  5. No tests in the project: a throwaway check lives only in the scratch copy and is never added to your project. A "fix" in such a project goes through this path.
  6. Safety carried over: your real files change only after your OK; broken or clashing test code is caught (duplicate imports, a clashing const rows, made-up asserts like assert.include); small data files such as trades.json are shown to the model.
  7. Screen: a "Plan" list at the start, a live try counter (Trying fixes (2 of up to 8) ✗ ●), finished lines like ✗ ✓ passes all 4 tests, a rename prompt showing every file, and a test-approval prompt. --no-flows forces step-by-step mode.
  8. Tests: 59 automated tests. The last full run was 51 of 51; the 8 added since (7 for the new paths, plus 1 real-terminal test of the new prompts) pass on their own.
  9. First real-model check on the 5 old practice tasks: 4 of 5 in one run (fix in 12 s, --json in 51 s, rename, the question; round 1 got 0–2). titleCase passed in some runs and not others.

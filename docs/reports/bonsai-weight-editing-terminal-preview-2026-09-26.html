Editing weights — the terminal side

The editing itself happens in the browser, in the Weights tab. This page shows every moment the terminal is part of: the save note, switching models, checking what's loaded, and the one warning. Drawn with Bonsai's real colors, marks and picker layout.

26 September 2026 · companion to “Editing Bonsai's weights” (the plan report)

Who does what

The browser — the Weights tab

  • Click a row, a token or “copy from…”
  • ×2 · ×0.5 · off · custom
  • Preview in the Picture before saving
  • Edit list with undo, then Save

The terminal — Bonsai

  • The weights badge, lower right — says when edited weights are ready and when they're in use
  • /model — switch to the edited copy and back
  • /stats — which weights are loaded right now
  • The warning when memory can't hold the switch

The flow, moment by moment

1You press Save in the browsernew

The hub server runs inside Bonsai, so the note appears the moment the copy is written — and the weights badge lights up in the lower right, like Claude Code's corner. It stays there until you switch, so nothing depends on you remembering.

· Saved 27B · edited — 2 edits: ffn_up layer 12 row 3072 ×0.5 · word “king” off.

2You follow the badge: /modelpicker exists · second row is new

The same picker as today, with one new row. Arrow down to the edited copy, enter. You never close Bonsai or the terminal — only the model server behind it restarts.

3The switch runs — about 40 secondssame starting line as boot

Only the model server restarts; your window, conversation and history stay. It always says reading, never restoring — new weights never reuse an old warm-up. You can type meanwhile; it sends when ready.

bonsai — Terminal
✻ Starting 27B · edited… reading its instructions on the new weights, about 40 s (0:12)
> Ask anything — it sends as soon as the model is ready
  ? for shortcuts

4It's ready — and /stats tells the truthmodel row is new

One dim note when the switch finishes — and the badge changes to say what's loaded now. It stays as long as you're on edited weights, so there's never a doubt. /stats has the full detail.

5The one guardnew

Only one 27B fits in memory. If a second Bonsai window still holds the original, the switch warns instead of starting.

bonsai — Terminal
· Another Bonsai window is using Bonsai 2 27B. Close it first, then switch.

6Going back

The same picker in reverse: /model → Bonsai 2 27B → ~40 s → the original weights, exactly as they were, and the badge goes away. Undo is never more than that — and still no closing anything.

What changed
  • models/runtime/memory.mjs: macMemory() reads total, free, compressed, swap and pressure (vm_stat + one sysctl, about 5 ms).
  • models/runtime/server.mjs: footprintOf(pid), shared with the existing RAM meter, so the welcome can measure a Gemma that's still loaded.
  • terminal/src/app/mac-memory.mjs (new): the snapshot at open, the bar's parts, the footer words.
  • screen.jsx: the Split bar beside the welcome box (shown at 106+ columns) and the footer readout. App.jsx / cli.jsx: measure at open, refresh the footer every 5 s. theme.mjs: two colours.
  • terminal/test/mac-memory.test.mjs (new, 6 tests), including the real app in a terminal.
Tests: the full suite 390 of 390 on 3 runs. One earlier run had 1 failure that didn't repeat, while another session was running its own suite and a Gemma bench on the same Mac.

Way 3: the side file

A side file cannot be trained here, so this only tests the connection. Two hand-made files of one megabyte each tie the chance of “ Tokyo” to that of “ Paris”: one is built from the real row of the word, one from the row as the file stores it. The question is always the same: “The capital of France is”.

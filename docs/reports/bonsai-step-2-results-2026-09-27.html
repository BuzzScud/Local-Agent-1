What I got wrong on the way

  • “exit” already quits. My first findings and the first plan page said a plain exit does not quit. It does, since 26 Sep; your two exit lines were typed before that. I had checked the sorting rules and not the app’s own check. The change was dropped and the numbers corrected: 17 of 81 became 15, and 14 → 2 calls became 12 → 2.
  • Two runs at once. I stopped the first real-model run to restart it safely, and its wrapper started the second half by itself, so two runs shared one model for about 25 seconds. I stopped both, threw their results away and started one clean run.
  • A follow-up rule that was too loose. My first rule took “tell me about multiplication, how does it work?” for a follow-up because of the word “it”. The trap lines caught it; now the “it” must sit right after the verb.
  • A command rule that was too wide. “build a login page component in Login.jsx” was taken for a plain command. The trap lines caught that too; a command that names code is left to the brain, as before.

Limits you should know

  • The answers to pick are guesses. The brain sees file names, not what is in them. It offered “Fix dark mode styling” in a project with no dark mode. “Type an answer” is always there.
  • In your home folder the gain is small. Your saved conversations show the brain already handled “ima need help” and “add it to my desktop” well there. The shortcuts, where a wrong sort costs most, only run inside code projects.
  • Short requests still get asked about. The brain called all 8 short requests unclear, “add a json flag” too. Not changed: you chose “ask whenever unclear”.
  • Follow-ups are found by word rules. “what about the other one?” is missed and sorted as before. A line that names a file or code is never taken for a follow-up.
  • Start to finish, nothing got faster for the nine moved requests: 155 s before, 159 s after, one run each. The 2.3 s saved at the start is smaller than the swing in what the brain does next (“TEST” took 11 s, then 38 s; “commit and push” 41 s, then 16 s). The whole set went from 899 s to 827 s, which one run cannot credit to these changes.
  • The pick list costs 2.4 s on each question the brain writes (6.4 s to 8.8 s). Questions with a set wording are as fast as before.

How it works

The notes stay where they are. Bonsai never changes them.

1At every start

Bonsai reads fifteen short lines on how you like things done. About 8 seconds of reading, once per start.

2When you ask

A small model compares your request with every note, by meaning and by the words they share. It takes less than a tenth of a second.

3If a note fits

The part of it that fits goes along with your request, about 1,100 characters. If none fits, nothing goes along.

4Always current

The notes are read where Claude keeps them. A note written today is there today.

The 15 lines, for you to read

Boiled down from the 52 notes on how you like things done, and put in Bonsai's words. Nothing here is in your real Bonsai yet: they go in only when this round is merged. A line you remove later does not come back.

  1. Explain simply: the result first, then a few short steps. No file names or code unless the user asks.
  2. After you make a page or a file, say exactly where it is, with its full path.
  3. Never delete with rm -rf or a wildcard. Look first, and move things aside instead of deleting them.
  4. One step per command: do not chain stop, clean, restart and test in one line.
  5. A finished page or report is ONE self-contained .html file with <meta charset="utf-8">, on the Desktop unless told otherwise.
  6. When you revise a file you already handed over, keep the original and write a new one (name-v2).
  7. If a file the user named is missing, say so at once and ask where it went. Do not work around it.
  8. Before a job that takes more than a few minutes, say how long it will take.
  9. Never say a check passed unless you ran it and read what it printed.
  10. A simple request is done with few questions. Ask only what the files cannot tell you.
  11. Commit or push only when the user says so, and never commit a key, a token or a password.
  12. Before you delete or move many files, make a backup first.
  13. A preview shows the real thing with real data, not a mock-up.
  14. "Uniform" means the same parts with the same ends and heights in every repeated piece.
  15. In a design: no thin coloured stripe on the edge of a card, and nothing that makes the page scroll sideways.

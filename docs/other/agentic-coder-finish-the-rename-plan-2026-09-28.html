The 5 places that are wrong today

  1. The nightly memory review can't be scheduled. It looks for the app under the old folder and old name, which are gone, so it would stop with "the bonsai app is not installed".
  2. Commands the agent runs inherit the app's restart setting. The launcher sets it under both names; the code only removes the old one.
  3. The update-check timers only answer to the old names. Setting the new name does nothing.
  4. The docs mirror's off switch and the background memory save also know only the old name.
  5. Two on-screen messages tell you to set old-named switches, and the Hub page tells you to look in a folder called "bonsai-code DOCS".

How I'll avoid last time's mistakes

The first rename pass used one blanket find-and-replace and broke three things: the greetings ("hello bonsai" stopped counting as small talk), an environment setting written in a form that silently stopped a test file from loading, and patterns hidden behind \n in strings. This time each group of files is changed on its own, I read the whole difference before running anything, and the tests run after every group.

What this shows, and what it does not

  • It is one test, run once each. It says how Low and High behave on an easy, clear bug. It does not say which is better in general. The plan's rule needs all 28 tests: High must pass at least 2 more than Low.
  • The first test run failing is the point of the test (the bug is real), not a mistake.
  • Both made the same change, line for line.
  • High's fix call wrote 2,226 tokens. Thinking stops at 2,048, and the fix itself is about the size of Low's (164 tokens), so High thought up to its cap: about 3 minutes at 12 tokens a second, for the same three lines.
  • The bench's own summary says 0 tokens for both runs: it counts only the chat's stream, not the fix tries (the same gap the Musing line had). The counts here come from the model server's log.

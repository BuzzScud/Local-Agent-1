Why it went this way

  1. Request 2 did nothing new because the conversation still held request 1. Qwen saw its own earlier page and answered from memory, without opening the file.
  2. Request 3 lost 2½ minutes to a save that could never work. After /clear Qwen didn't know the file existed, so it put the whole page into one Write. Write only makes new files, and nothing told Qwen that before it started writing.
  3. No one opened the page in a browser. Qwen said it would read the file back and didn't. The side check compares the request with the change; it doesn't run the page. In request 3 Qwen read all 206 lines and still called the page complete. The dead button got past all three.
  4. The notes it brought along were about something else. Both were Claude's rules for report pages, matched at only 0.58–0.60 closeness. In request 2 Qwen spent part of its thinking comparing the widget against them ("no file picker or run again").

The Opus 5.5 and Fable 5.1 harness

The harness is everything around the model. It gives the model the task, runs the tools the model asks for, keeps the conversation from getting too long, hands a turn to a backup model when a safety check trips, and grades the result. This page is drawn from the two system cards: Fable 5.1 (1 Sep 2026) and Opus 5.5 (22 Sep 2026).

1 · One agent: the loop (both models)

Every test with one agent follows this loop. For the coding tests, the harness is Claude Code itself, the same program as this terminal, run in its stripped-down mode (no hooks or plugins).

2 · Teams: the two shapes both cards tested

Instead of one agent, several copies of the model work on the same task at once. Both cards used the same two setups on ProgramBench, where the job is to rebuild a program from only its compiled file and its manual.

Fable 5.1

The team of five reached a score of 0.6 about 2× sooner than one agent.

Lead + helpers was faster than one agent and finished with the highest final score.

Each agent had a shell and up to 1M tokens.

Opus 5.5

The team of five reached 0.6 about 2.7× sooner. Lead + helpers landed in between.

The single agent got 20M tokens and summarizing, so the teams' extra tokens weren't an unfair edge.

On research reports with half the time, the team of five matched or beat one agent's score about 2.8× faster. When time was very tight, the lead mostly stopped starting helpers and worked like a single agent.

What changed in the harness between the two cards

  • Screen tests keep every screenshot now. The old setup threw away old screenshots. The new one keeps them all and summarizes the conversation once it passes 100k tokens. Fable 5.1 was re-scored this way (80.7% partial), which replaces its number in its own card.
  • The bug-hunting test was rewritten. It used to be called OSS-Fuzz. Every older model was run again, and the new scores are higher, so they can't be compared with older cards.
  • The prompt-injection test got more time per turn in an updated Cowork harness, and the three older models were run again in it.
  • The escape watcher was added and the big-team tests are new (see above).
Notes
  1. The Opus 5.5 card says its weapons check "behaves similarly to previous models like Claude Fable 5.1" with no backup model. The Fable 5.1 card doesn't list a check for copying the model, which doesn't prove it has none.
  2. The Opus 5.5 card says the big-team results, and its team-of-five ProgramBench run, come from a slightly different version than the released one, with similar performance.
  3. No single harness exists. Each test has its own setup, and a few run in other companies' agents (Cursor's, Proximal's, MathArena's). This page draws the shape those setups share.

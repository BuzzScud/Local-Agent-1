Bonsai Code: how the folder is structured

One repo, two parts. terminal/ is the agent you talk to; models/ holds the models it runs and the bench that tests them. They meet at one file, models/index.mjs. The model's weights and your conversations live on this Mac, outside the repo.

terminal/ · part 1118 files · 5,900 lines of code in src/ · the screen, the loop, the focused paths, the tools
models/ · part 2308 files · 2,900 lines of code + 28 practice projects · one folder per model, the runtime, the test bench
On this Mac, not in git~/.bonsai-code: the 6.7 GB model, 418 MB of saved warm-ups, llama-server, your sessions · the installed bonsai

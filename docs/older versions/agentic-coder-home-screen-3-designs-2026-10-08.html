How these were made

Each frame is the app's own drawing, read cell by cell from a pseudo-terminal: coding in a sample project with ten saved conversations, a stand-in model server that takes about six seconds to load, and the app's real commit history as What's new. Frames were taken every half second while it loaded and four times a second once ready, the speed the page moves at. Colours are Terminal's 256-colour palette on its dark background.

The code is in terminal/src/app/home-looks.jsx. A pick is kept in settings.json as homeLook; AGENTIC_HOME_LOOK=zen coding tries one for a single window. A click on a conversation opens it in every look.

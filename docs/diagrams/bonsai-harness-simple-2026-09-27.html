The Bonsai harness, simply

Bonsai 2 27B is the brain. The harness is everything around it: it sorts your request, hands the brain its tools, keeps your Mac safe, and checks the work before it says “done”.

1You ask
You type a request and press Enter.
2It sorts
“Hello” gets a sentence back. An unclear request gets one question first. Then it picks the kind: rename, fix, change or question.
3It works
Rename, fix and change each have a shortcut built for them. Everything else goes step by step, one tool at a time.
4It checks
If files changed, the tests run and a second look asks: is every part of the request done? A miss goes back to step 3.
5Done
It tells you what changed, in a sentence or two.

Inside step 3: step by step

The brain never touches your files itself. It asks for a tool, and the harness decides.

the brain
Picks one tool It thinks, then asks for exactly one.
the harness
3 safety gates Blocked words, your OK, the fence.
the harness
Runs the tool Read, List, Search, Edit, Write, Bash, TodoWrite, Ask.
the result goes back to the brain, up to 40 steps

The loop ends when the brain answers instead of asking for a tool. Then on to step 4.

The 3 gates

  • Blocked words. rm -rf, sudo, git push and kill never run.
  • Your OK. Changes and commands are shown to you first.
  • The fence. macOS keeps every command inside the project.

Its memory

  • About ¾ full. Old tool output is cleared.
  • Still too full. It writes itself a summary and carries on.
  • “update memory”. Saves notes it reads at every start.

When it asks you

  • Unclear request. One question before it starts.
  • Before a change. It shows you what it is about to do.
  • Looking too long. 8 looks or 5 minutes with nothing changed.

When it stops itself

  • 40 steps. The most one request can take.
  • Going in circles. The same step over and over, or 5 errors in a row.
  • You press Esc. It stops and waits for you.

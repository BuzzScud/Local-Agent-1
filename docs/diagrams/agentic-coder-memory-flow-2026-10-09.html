How Agentic Coder's memory works

9 Oct 2026 · from the code in terminal/src/agent

A loop: the model reads the memory when it starts and with each request, then saves what it learned for next time.

The memory

One small text file per fact, kept only on your Mac.

Nothing is ever deleted: an old fact is retired.

1A window opens

The model reads your Always rules (up to 20) and one short line per fact (up to 1,600 characters).

reads memory

2You send a request

A small local model finds the 5 facts closest in meaning and adds them to your request.

reads memory

3The model does the work

It uses the facts that fit. Where a memory and a file disagree, the file wins.

uses memory

4It can save as it works

With its Remember tool: one short sentence about you or about the project.

saves memory

5The round ends

About 10 seconds later, a second look reads what happened and saves up to 5 new facts.

saves memory

6The window closes

The whole conversation is read once more, and anything new is saved for the next start.

saves memory

How it keeps itself tidy

A fact helped

The check passed, so its trust goes up.

A fact misled

The check failed, so trust goes down. At −3 it is retired.

A fact went unused

Not brought up for 30 days, so it is retired.

Never saved

Keys, tokens, passwords, repeats, and practice runs.

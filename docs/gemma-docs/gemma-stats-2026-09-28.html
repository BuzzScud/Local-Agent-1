Speed

Writing speed is what you feel while it works. The speed helpers guess the next word; Gemma checks each guess and keeps only what it would have written anyway, so the text is the same, just faster.

Checking 2 words costs Gemma only 1.19× the time of 1, so one guess pays. Checking 4 costs 2.4×, so longer guesses lose time when they miss.

Read it with this in mind

  1. One run each. A single pass or fail can be chance: Gemma’s task 18 (a story that must have enough sentences) has failed by chance before. A flip of one task is not a trend.
  2. Thinking on only. Thinking off was not run tonight, at your word. Your app runs thinking on at High, so this is the setting closest to how you use it.
  3. Not your app’s exact settings. The app is set to 64k context, an 8,192 thinking cap and the Qwen reranker. The test used 32k, 4,096 and no reranker, the same for both models. Tab 4 shows how far the runs stayed from those limits.
  4. Time is from the first request to the last reply of each run; loading the model is not in it. A run that reached 15 minutes was stopped and counts as a fail for that prompt.
  5. The renames (8, 9) take no model call and pass either way.
  6. A task counts only when all four runs finished, so both models are judged on the same tasks.
  7. Two lines in the Tests tab for each model. The first part wrote a results page and a Tests-tab line at 6:03 (22 tasks). After part 2, a second page and line cover every task counted; this page uses the second.

All three sets change in one place: Battle tab → Edit tests

Open the Battle tab (/battle in the app, or coding battle), click Edit tests, pick a test on the left, change its prompt, starter files or checks, and press ⌘S. The list is grouped: New 28, Work 28, Practice 28, then your own tests.

What Save does, set by set
Work 28Changes the test. Put back the original brings it back as it came.
New 28The same: changed in place, with Put back the original.
Practice 28Makes your copy with the next letter: edit 18 and you get 18b (then 18c …). Test 18 itself never changes, so Gemma's 27 of 28 still means the same thing. The copy sits right after 18, marked "copy"; editing it changes only the copy. A deleted copy's letter is never used again, so old results never land on a new test.
My testsYours: + New test adds one in 3 steps.
Nothing is ever deleted: a deleted test, an edited copy you put back, and cleared results all go to ~/.agentic-coder/battle/trash/.
Where each set lives
battle/work28/the Work 28 as they come with the repo, each with a known-good answer
battle/new28/the New 28, the same way
bench/tasks/the Practice 28 (the grade), never changed by the Battle tab; battle/practice28.json gives each its title, kind and rules
~/.agentic-coder/battle/tests/your copies: what the Battle tab runs and edits

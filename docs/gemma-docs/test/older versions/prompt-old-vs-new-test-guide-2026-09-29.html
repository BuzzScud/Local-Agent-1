Before you start

The 28 practice tasks, with the old prompt and the new one

Each model does the Practice 28 twice: once with the prompt from before 30 Sep, and once with the new one (the Work habits block Opus and Fable work by). Only the prompt differs. A results page then shows both side by side, and a line lands in the hub’s Tests tab. About 1–1½ hours a model, 2–3 hours for both, mostly waiting.

Do these three things first
  1. Open Terminal and put it beside this window.
  2. Quit Agentic Coder: type /exit in every Agentic Coder window. Only one model fits at a time.
  3. Plug in the Mac. The test keeps it awake by itself.
Nobody has run this test yet. The dark “Terminal should print” boxes show the exact lines the test prints; the yellow parts (N) are where your numbers go. The rule, set before any run: the new prompt holds when it passes at least as many tasks as the old one and takes at most 10% longer.
Step 1 of 5 a few seconds

Free the model

The app keeps its model loaded for 30 minutes after you close it. This unloads it so the test can load its own.

1Type this into Terminal
%coding stop
2Terminal should print one of these · either is fine
Stopped the model on port 17600; its memory is free. — or — No model is loaded.

If it printed something else

“Still in use by an open Agentic Coder window”
An Agentic Coder window is still open. Type /exit in it, then run the command again.
“command not found: coding”
Type this instead: ~/.local/bin/coding stop
Step 2 of 5 about 10 seconds

Make a test copy of the new code

A copy nobody else edits, so a Claude session changing the app can’t change the code between the old run and the new one. Your main folder is untouched, and the results still go there.

1Type this into Terminal · one long line; Copy takes all of it
%cd ~/Desktop/agentic-coder && git fetch -q origin && git worktree add --detach ~/worktrees/prompt-test origin/main && ln -s ~/Desktop/agentic-coder/node_modules ~/worktrees/prompt-test/node_modules && mkdir -p ~/Desktop/agentic-coder/cli\ docs/gemma-docs/test/prompt-old-vs-new-tests && echo "copy ready"
2Terminal should print
Preparing worktree (detached HEAD 1a2b3c4) HEAD is now at 1a2b3c4 … copy ready

If it printed something else

“already exists” about ~/worktrees/prompt-test
A copy from an earlier try is there. Run git -C ~/Desktop/agentic-coder worktree remove --force ~/worktrees/prompt-test, then press Copy above again. That removes only the test copy.
“File exists” about node_modules
That’s fine. The link was already made. Type echo "copy ready" and go on.
Step 3 of 5 about 1–1½ hours

Stop here and tell Claude

An error about memory, or the model not loading
A model is still in memory. Run step 1 again, wait a minute, then press Copy above again.
A line starts with FAIL
That’s a result, not a failure of the test: a task’s own check did not pass. Let it finish.
Stuck on one task for over 15 minutes
Press Control C once. It saves what ran, skips the rest, and still makes a page, marked as a part run. Everything it printed is in qwen.log in gemma-docs → test → prompt-old-vs-new-tests.
You want it the way your app is set
Add --think on to the end of the command: thinking at High, like your app. It takes about twice as long.

Step 5 of 5 a few seconds

Open the results

This opens the newest results pages, one for each model. They are also on each run’s line in the hub’s Tests tab.

Say the two verdicts. If the new prompt holds, nothing more is needed: it is already on in the app. If it does not, name the model; the old prompt comes back for everyone with AGENTIC_PROMPT=old while the habits are fixed.

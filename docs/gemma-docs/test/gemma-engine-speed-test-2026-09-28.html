Engine speed test: official llama.cpp vs Prism's build

Gemma 4 12B on this Mac, 28 Sep 2026. Same model, same settings as the app (32k, two slots, 8-bit cache), one engine at a time, the four prompts the speed-probe round used.

Keep Prism's build for now: it writes 5% faster with the helpers.

With the app's two speed helpers on, Prism's build averaged 16.7 words a second and the official build 15.9 (-4.7%). Tool calls and thinking worked on both.

version 2 · on main since 94df3ab
Before you start

The 28 practice tasks at High, the old way of thinking and the new

Each model does the Practice 28 twice with thinking on: once the old way (every test and draft thinks first, up to 2,048 tokens, until the 15-minute limit cuts it off) and once the new way (the first tests and drafts are written straight away, a try after a miss thinks, and past 7½ minutes it thinks only briefly). Only the way thinking is spent differs. Low is the same both ways, so it isn’t run.

Do these three things first
  1. Open Terminal and put it beside this window.
  2. Quit Agentic Coder: type /exit in every Agentic Coder window. Only one model fits at a time.
  3. Plug in the Mac. The test keeps it awake by itself. Both models take about 6 hours, so it’s an overnight run.
The rule, set before any run: the new way holds when it passes at least as many tasks and takes at least 15% less time in all. (Two runs of the same code have differed by about 10% by chance, hence the margin.)
It runs from a test copy, ~/worktrees/think-when-it-pays, frozen at 94df3ab (the change as pushed to main), so another session changing the app can’t change the code between the old run and the new one. The results go to your main folder and the hub’s Tests tab.
Step 1 of 4 a few seconds

Free the model, make the log folder

The app keeps its model loaded for 30 minutes after you close it. This unloads it so the test can load its own, and makes the folder the logs go in.

1Type this into Terminal
%coding stop; mkdir -p ~/Desktop/agentic-coder/cli\ docs/gemma-docs/test/thinking-old-vs-new-tests && echo "ready"
2Terminal should print one of these, then ready · either first line is fine
Stopped the model on port 17600; its memory is free. — or — No model is loaded. ready

If it printed something else

“Still in use by an open Agentic Coder window”
An Agentic Coder window is still open. Type /exit in it, then run the command again.
“command not found: coding”
Type ~/.local/bin/coding stop first, then the command again.

Stop here and tell Claude

An error about memory, or the model not loading
A model is still in memory. Run step 1 again, wait a minute, then press Copy above again.
A line starts with FAIL
That’s a result, not a broken test: a task’s own check did not pass. Let it finish.
A line says “Half of the 15 minutes for this request are gone”
That’s the new way stepping down on a long task. Expected, and counted on the page.
You need the Mac before it ends
Press Control C once. It saves what ran, skips the rest, and still makes a page marked as a part run. The log is qwen.log in gemma-docs → test → thinking-old-vs-new-tests.

What these tests show, and what they don’t

  • They show that Gemma runs well on this Mac: speed, memory and long reading were all measured carefully, some of them twice.
  • They don’t show how well it codes. That rests on 9 tasks run once each, one bug fix run many times, and one failed page. That is too few to grade with confidence, so the coding grades may still move either way.
  • They don’t show that thinking helps. So far it has only made the same answers slower.
  • One run at 12:30 is left out: two copies of Gemma were loaded at once, so there was no memory for the second, and every answer came back empty. It is not a Gemma result.

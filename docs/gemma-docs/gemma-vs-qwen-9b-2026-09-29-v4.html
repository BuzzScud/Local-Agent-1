Gemma 4 12B vs Qwen3.5 9B

The two models in Agentic Coder's /model, side by side · 29 Sep 2026 · version 4

Same app limits and about the same file size. Qwen is smaller (9B vs 12B), reads prompts faster, and with its own MTP helper writes about as fast as Gemma with hers (18.1 vs 17.2 tokens/s on the same 4 tasks). Its cache costs about twice as much per token, so it uses less memory up to about 156k tokens and more past that. Gemma has our B grade on the 28 tasks; Qwen has not been graded yet.

MTP wins: Qwen now runs on its MTP build. With its own MTP, Qwen writes 1.12× as fast (18.1 vs 16.2 tokens/s), a little faster than Gemma with hers (17.2). Higher = faster.

Speed test: how it was measured

  • Same 4 tasks, token limits and prompts as Gemma's probe; 2 runs each, the cache cleared between runs, so each run reads and writes from scratch. Each model uses its own maker's sampling settings.
  • Qwen ran through Agentic Coder's own server code at your 64k and 2 conversations (29 Sep). Gemma's probe ran on a bare server at 32k and 1 conversation (28 Sep), which is a little kinder to speed: take small gaps as a tie.
  • Write speed only (tokens per second: higher = faster). Reading speed is not part of this test (Qwen reads ~190 tokens/s, Gemma ~127).
  • "Guesses kept": of the words guessed ahead (by MTP and by n-grams), how many the model kept. Rejected guesses cost a little time.
  • The rule was written before the run (rule.md): at least 1.10× faster over the 4 kinds with 2 conversations (1.30× if MTP needed 1), no kind below 0.95×, no errors.
  • Raw runs: models/qwen3.5-9b/results/mtp-speed-2026-09-29/ (runs.jsonl, summary.json, rule.md) and models/gemma-4-12b/results/speed-probe-2026-09-28/.

What the other numbers do and do not show

  • Memory rows and the chart are the app's own estimate of the whole model (file + cache + running state + helper + working space). Where a square marker or "measured" appears, it was measured on this Mac: Gemma's are 0.3 GB under the estimate.
  • Gemma's speeds were measured on 28 Sep; Qwen's in one quick check on 29 Sep (answered "42" to 6×7, called the Read tool when asked to open a file, and at High wrote 1,927 tokens in 149 s on a one-line maths question). One run each: a first look, not a benchmark.
  • Both models now write with their own MTP helper. Qwen's is a layer inside its model file (Unsloth's MTP build, since the speed test of 29 Sep); Gemma's is a separate 0.5 GB file from Google.
  • Qwen has not done our 28 practice tasks, so there is no grade to compare yet. Its MMLU-Pro is Qwen's own figure, not ours.
  • Only one of the two fits in memory at a time: on 29 Sep, Qwen at 64k and another Gemma at 16k ran the GPU out of memory.
